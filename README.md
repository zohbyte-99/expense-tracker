# Expense Tracker

A  console-based Expense Tracker built with Python.  
The application allows users to manage their daily expenses through a simple command-line interface.

## Features

- Add new expenses
- View recorded expenses
- Update expense information
- Delete expenses
- Organize expenses by category
- Calculate total expenses
- Simple and easy-to-use console interface
- Data management using Python

## Technologies Used

- Python
- Object-Oriented Programming (OOP)
- Python Lists / Dictionaries
- File Handling (if applicable)

## How It Works

The application runs in the terminal and provides users with different options for managing their expenses.

Example:

```text

1. Add Expense

4. Delete Expense
